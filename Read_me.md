# A simple html game

A lightweight, browser-based 2D grid game built using vanilla JavaScript, HTML, and CSS. Players navigate through a maze-like arena to collect randomly spawning coins while avoiding walls and navigating dynamic game boundaries.

## Features

* **Real-Time Collision Detection:** It determines collision between  player, wall, and coins.
* **Smart Item Spawning:** Coins dynamically respawn in clear, playable areas, avoiding static obstacles like walls and HUD elements.
* **Built-in Timer:** Tracks player performance in real time.
* **Smooth Movement:** accurate player controls using arrow keys.

## How to Play

1. Open `my_game_html` in any web browser.

2. Use the **Arrow Keys** to move the player around the board:

   * `ArrowUp`: Move up
   * `ArrowDown `: Move down
   * `ArrowLeft `: Move left
   * `ArrowRight `: Move right

3. Touch coins to trigger a new coin spawn!

## Built With

* **JavaScript (ES6+)** - Core game loop, collision algorithms, and state management.
* **HTML5** - DOM layout and game canvas elements.
* **CSS3** - Game container styling and absolute positioning system.
